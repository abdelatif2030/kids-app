# Learning adventures

Data: `lib/curriculum/learning_adventures.dart`; shown on the weekly adventure screen (`LearningPathCard`).
A learning adventure **adds no reward, star or progress**. It joins pieces that already exist, in five steps:

| Step | Source | Counted in the app? |
|---|---|---|
| Discover | an existing story, branching story, real activity or everyday task (first one that fits the age) | no |
| Learn | the first curriculum unit of the adventure that fits the age | no |
| Play | the games of the same weekly theme (the existing weekly adventure steps) | yes: the weekly adventure record |
| Apply | a real-life task with a grown-up (everyday task / real activity) | no: a parent confirms elsewhere |
| Celebrate | the weekly adventure record that already exists | existing system only |

Six adventures, one per weekly theme: letters, numbers, animals («عالم الحيوانات»: story → names → where it lives →
what it eats → feed a pet), thinking, listening, shapes. Tests check every reference exists, every game belongs to the
theme, and every age 1–6 sees something to discover and apply (and learn/play from age 4).
