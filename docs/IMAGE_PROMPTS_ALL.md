# كل سكريبتات الصور (برومبتات ChatGPT) — رحلتي

## الطريقة (مرة واحدة)
1. افتح شات جديد في ChatGPT وارفع أي شيت خلصان (مثلاً شيت عالم) وقول: **Use the attached image as the exact style reference.**
2. كل باك = **شيت واحد** (4 أعمدة × 3 صفوف = 12 صورة). انسخ البرومبت كامل (كل باك مكتوب ومجمّع تحت، مش محتاج تجمّع حاجة) والصقه.
3. لو الصور طلعت مش حلوة، اطلب نفس الشيت تاني. المهم: خلفية بيضاء، كل صورة في خليتها، ومفيش لمس بين الصور.
4. ابعت لي الشيت مع اسم الباك (مثلاً `veg`) وأنا أقطّعه وأشغّل الكلمات والأصوات.
5. الباك بيشتغل في اللعبة لما كل صوره الـ12 تجهز.

## ملاحظات سريعة
- لو حاجة طلعت "فيها نور أو ضل أو لمعة بعيدة" ارفضها واطلبها تاني: الشيت لازم يكون خلفية بيضاء نضيفة.
- العناصر البيضاء (زي السنة أو الورقة) لازم يكون ليها حد رمادي-أزرق خفيف، وإلا بتتمسح في القص.
- باك `shapes` لسه ما اتجرّبش في الكلمات، وأنا هراجعه معاك أول ما يوصل.
- عوالم جديدة (اختياري): وصفة العالم (بانوراما + أرضية + شيت ديكور + شيت منصات) موجودة في docs/IMAGE_SCRIPTS_NEXT.md. أفكار: مزرعة بالليل، مخيم جبلي، ملعب، سوبر ماركت، مطبخ، أوضة نوم، مدرسة، مستشفى، مطار، حديقة حيوان، شارع رمضان بالفوانيس.
