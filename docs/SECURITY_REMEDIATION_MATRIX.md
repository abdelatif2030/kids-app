## Also fixed while reviewing (code, verified locally)
- The in-memory family "demo" could, by a build flag, have been switched on in a release build (fake family data). It is now impossible: `kFamilyDemo` requires a non-product build.
- The sign-in screen text claimed there were no chats in the app; it now describes adult-only messages.
- A failure other than a wrong password (no network, unexpected error) used to escape the sign-in screen; it now shows a message.
- The Parent-settings tiles for the teachers service and family chat said "approved teachers" / invited a tap; they now say "Not available in this version yet" while the gate is closed.
