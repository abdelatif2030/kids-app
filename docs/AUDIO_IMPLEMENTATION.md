# Rehlaty — audio implementation

One speaker: `RehlatyAudioEngine` (`lib/media/rehlaty_audio_engine.dart`). Companion, guides, games, stories and greetings all call it; no feature has its own audio path.

- Queue with priorities (low/normal/high), repeat guard (30 s per line), ducking of music while speaking, pause/resume/stop, cancel flag against races.
- Parent settings (Sound settings): master switch, characters on/off, per-character switches, automatic narration (off by default), narration/music/effects volume,
  language (auto/ar/en), a voice per character and language, and the companion switch.
- `AudioGate`: a family call or the app leaving the screen silences lessons, stories and characters.
- Lines: `kDialogue` in `audio_catalog.dart` (now 28 companion lines `cp_*` by Adam and Nour). A line plays an approved recording only if the file exists AND its id is in
  `assets/audio/voices/approved.json`; otherwise the phone's own text-to-speech reads it.

## What is not real yet
- **Zero human recordings, zero approved recordings.** Every character line is the phone's demo voice (`docs/VOICE_ASSET_STATUS.md`, generated by tests).
- 19 sound effects and 6 music tracks are catalogued but their files do not exist, so those cues are silent.
- Adam (pitch 0.92, rate 1.05) and Nour (1.12, 0.97) tuning was chosen by reasoning and has never been listened to.
- No audio test was run on a real device. Offline behaviour is by design (device voice, no network) but unverified on hardware.
