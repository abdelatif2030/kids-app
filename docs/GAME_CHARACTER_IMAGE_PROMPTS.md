# صور شخصيات «برج الأبطال» و«ركضة السحاب» — البرومتات (2026-11-18)

دلوقتي الشخصيات مرسومة بالكود (كرتونية بسيطة). لو عاوزها **زي الفيديو بالظبط**، ولّد الصور دي وابعتها، وأنا أركّبها مكان الرسم بالكود.

## قواعد عامة لكل الصور
- خلفية **شفافة** (PNG)، من غير أي كلام على الصورة، حجم الصورة مربع إلا لو مكتوب غير كده.
- أسلوب واحد لكل لعبة (اكتب السطر ده في أول كل برومت): ثبّت نفس الأسلوب عشان الشخصيات تطلع من نفس العيلة.
- ممنوع دم أو أسلحة مخيفة أو وجوه مرعبة: للأطفال 3-6 سنين.
- ملف لكل وضعية، الاسم زي المكتوب (عشان أركّبهم بسرعة).
