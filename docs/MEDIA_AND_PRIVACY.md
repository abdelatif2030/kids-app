# Media, storage and privacy (what the app actually does)

## What is stored, and where
Everything is on the device (`shared_preferences`, a local file on Android/web storage). Nothing is uploaded. There is no analytics, advertising or tracking SDK.

| Key | Content | Deleted by |
|---|---|---|
| `rj_profiles`, `rj_attempts`, `rj_custom`, `rj_settings`, `rj_active` | child profiles (nickname, age, interests, goals, plan), finished activities, admin content | child deletion / "delete all" |
| `skill_events` | one row per answered question (skill, right/wrong, letter or color) | child deletion / delete all |
| `learning_records` | exposure / practice / demonstrated rows (letter, word, story, lesson, activity, creation) | same |
| `story_state` | per child: favorites, resume position, listening history | same |
| `literacy_state`, `literacy_config` | per-letter review box and due date; parent's progression choice | child deletion (state); config is a setting |
| `home_tasks` | offline tasks and parent confirmations | same |
| `family_gallery` | drawings (stroke points), scenes, characters, picture-story emoji | child deletion, or the parent gallery screen |
| `watch_history`, `used_*`, `bonus_*`, `parent_notes`, `plan_target_*` | video history, time used, notes, weekly goals | delete all |
| `audio_*`, `text_scale`, `reduce_motion` | parent's sound and display settings | kept |
| PIN (secure storage), time limits | parent security | kept by "delete child data" |

A child's real name, photo, voice, location and contacts are never asked for. The nickname is chosen by the parent. The child types nothing: stories-by-pictures and scenes use pictures only. No microphone or camera permission is needed.

**Parent tools:** export one child's data as readable JSON (copy), delete one child completely, delete everything, delete gallery items, report a problem (a message the parent sends themselves).

## Audio: real versus placeholder
| Item | Status |
|---|---|
| `assets/audio/rain.mp3`, `waves.mp3`, `wind.mp3` | **Real files**, original, generated by script (synthetic noise). Ambient loops; they sound like soft noise, not field recordings. |
| `assets/audio/musicbox.mp3` | **Real file**, original synthesized melody (62 s). The only item that plays through the file player with real seeking. |
| Story narration, letter names/sounds, word pronunciation | **No recordings exist.** The device's own text-to-speech reads them. Labelled "تجريبي" in stories. If no Arabic voice is installed, playback is disabled with a message. |
| Pictures | Emoji (the platform's font), not licensed artwork. |
| Videos | Whitelist `assets/videos.json`, official YouTube player only; not reviewed by a human yet. |

Each story records its source and rights (`Story.source`, `Story.rights`); all eight written stories are original texts made for the app. Nothing is copied from another work.

## Not implemented (do not claim)
Background and lock-screen playback (needs `audio_service`, untested on a device), downloads (no downloadable licensed audio exists), cloud sync/backup, notifications, payments.
