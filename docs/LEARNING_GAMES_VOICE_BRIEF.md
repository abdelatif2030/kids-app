# طلب تسجيل أصوات الألعاب التعليمية (لهجة مصرية)

**الملف المرفق:** `LEARNING_GAMES_VOICE_REQUEST.csv` (UTF-8، يفتح في Excel). فيه 3588 جملة وكلمة.

## الأعمدة
| العمود | معناه |
|---|---|
| file_name | اسم ملف الصوت المطلوب بالظبط، مثل `ea16f8e2.mp3` (ما يتغيرش، اللعبة بتدوّر بالاسم ده) |
| game | اللعبة اللي بتقول الجملة (أو «مشترك» / «من قواعد اللعبة») |
| text | الجملة بالكتابة العادية |
| text_with_tashkeel_reading | نفس الجملة بالتشكيل **ده اللي يتقرا** (تشكيل اللهجة المصرية؛ لو فيه فرق عن النص العادي اتبع التشكيل) |

## الصيغة المطلوبة للتسليم
- **ملف صوت لكل صف**: MP3، mono، 44.1 kHz، حوالي 96–128 kbps.
- **اسم الملف = عمود file_name بالظبط**، وكلها في مجلد واحد (أو ZIP).
- جملة واحدة في الملف، **من غير موسيقى ولا ضوضاء**، وقطع الصمت الزيادة: نص ثانية في الأول وآخر الملف على الأكثر.
- **مستوى صوت متساوي** بين كل الملفات (حوالي -16 LUFS).
- النبرة: صوت دافي ودود لطفل 3-6 سنين، لهجة مصرية، سرعة هادية وواضحة، من غير مبالغة أو صراخ. «أحسنت!» و«برافو» فرحانين، «جرّب تاني» حنينة.
- الأرقام والحروف تتنطق زي الأطفال بيقولوها (مش فصحى ثقيلة).
- لو في كلمة مش مفهومة اكتب لنا قبل ما تسجّل، ولا تغيّر النص.
