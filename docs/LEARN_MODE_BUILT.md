# وضع «اتعلّم» — اتبنى (2026-11-26) وإيه لسه محتاجه منك

## إزاي بيشتغل
1. شاشة «عايز تتعلم إيه؟»: عربي / English / Deutsch / Français.
2. بعد اللغة: اختيارين كبار: **🎮 يلا نلعب (مستويات رحلتي في التعلّم)** — زي ما كانت — و**📚 اتعلّم (اختار رحلتك)**.
3. «اتعلّم» = أقسام: الحروف، الأرقام، كل الحيوانات، حيوانات المزرعة، الحيوانات البرية، الطيور، حيوانات البحر، الحشرات، الزواحف والديناصورات، الألوان، الأشكال، الأيام، الشهور، الفصول، جسمي، المشاعر، الهدوم، العيلة، الأكل، الفاكهة، الخضار، الوظايف، المدرسة، الموسيقى، الجو، المواصلات، البيت، المدينة، يومي، حواليّا، حاجات كتير.
4. جوه القسم: **عنصر واحد بس قدام الطفل** (أسد، أو رقم 1، أو حرف أ)، الكلمة بتتقال **3 مرات** (عادي، ببطء، عادي) + الجملة («This is a lion»). لمس الصورة أو السهم الأخضر = اللي بعده، والسهم التاني = اللي قبله، 🔊 = يعيد الكلام كله.
5. فوق: زرار 🔎 (أو 🔢 للأرقام) يخليه يختار عنصر معيّن: للأرقام **لوحة أرقام يكتب عليها أي رقم لحد 100,000**، ولباقي الأقسام قايمة بالكلمات.
6. **الأرقام من 0 لـ 100,000:** كل رقم لحد 100، وبعدها المئات (200…1000)، الألوف (2000…10000)، وعشرات الألوف (20000…100000). الرقم بيتنطق مركّب من كلمات صغيرة («one hundred twenty three»، «مية وتلاتة وعشرين»…) — التسجيلات الصغيرة دي هي الناقصة.
7. آخر القسم: «خلصت كل حاجة!» وبعدين يعيد أو يرجع للأقسام. مفيش عدّاد ولا خسارة.
الأقسام والعناصر بتتولّد من الكلمات الموجودة، فأي كلمة جديدة تتضاف تظهر لوحدها.
