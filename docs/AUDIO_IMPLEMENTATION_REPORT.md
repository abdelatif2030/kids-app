# Audio implementation report (phase 3), 2026-10-30

Scope: children aged 3-6. Everything below is uncommitted. Audio could only be tested with a **fake speech backend**; no sound was heard by a person. Nothing here claims that a recording exists.

## What exists now (files)
- `lib/media/audio_catalog.dart`: the structured catalogue. 36 approved dialogue lines (8 categories: welcome, encouragement, instruction, congratulation, support, explanation, story, reaction; one instruction line per new game), each with speaker (Adam, Nour or the companion), Arabic (simple Egyptian colloquial) and English text, context, and the exact path where its recording must be saved: `assets/audio/voices/<character>/<lang>/<id>.ogg`. 19 sound-effect cues (game and interface) and 6 background-music areas, each with its file path. The six-step voice pipeline is written in `kVoicePipelineSteps`.
- `lib/media/rehlaty_audio_engine.dart`: the shared engine (extended, not rebuilt).
- `lib/media/engine_settings_screen.dart`: the parent screen (Parent settings > App settings > Character voices).
- `docs/VOICE_ASSET_STATUS.md`: generated by a test from the files that really exist on disk (so it cannot drift).

## Engine capabilities (all covered by tests with a fake voice)
| Capability | Status |
|---|---|
| One line at a time, no overlap between Adam, Nour and the companion | implemented, tested |
| Priority (low / normal / high): high goes first and cuts a lower one, even one that has not started speaking yet (a race the tests found and fixed) | implemented, tested |
| Same line not repeated within 30 s (unless forced); identical queued line not queued twice | implemented, tested |
| Pause, resume (re-says the line from its start: a phone voice cannot continue mid-sentence), stop, interrupt | implemented, tested |
| Music ducking: `musicFactor` is 0.25 while a character speaks, 0 when the master switch is off; `effectiveMusicVolume` = parent music volume x factor; listeners are told. The story ambient sound is connected to it | implemented, tested (engine); story hookup compiled and the story tests pass; not heard |
| Independent volumes: narration (reaches the voice), music, effects | implemented, tested; the effects volume has nothing to act on yet (no effect files) |
| Master switch, characters switch, one switch per character (Adam, Nour) | implemented, tested |
| Language: follow the app, or always Arabic, or always English | implemented, tested |
| Character identity: per character and language the parent picks an installed voice; plus a fixed pitch and pace for each character (Adam lower and brisk, Nour higher and gentler) | implemented, tested that the right values are used. **The values were chosen by reasoning, not by listening** |
| Approved recordings path: a line plays from its file only if the file is listed in `assets/audio/voices/approved.json`; otherwise the phone voice reads it. That list does not exist, so nothing is approved | implemented, tested with a fake player; never exercised with a real file |
| Lifecycle: stops when a call starts or the app goes to the background (no auto-resume); stops when a game screen is left; gate listener removed on dispose | implemented, tested |
| Offline: no network code anywhere in the engine | by design; tested only as "works with no connectivity object" |
| Settings persisted, damaged values fall back safely, only settings are stored (no child ids) | implemented, tested |
| No microphone: the test scans the engine and catalogue source for recording APIs | tested |
| Audio focus / respecting the device silent switch | **not implemented**: the text-to-speech plugin's platform behaviour is relied on; needs real-device checks |
| Caching of recordings | **not implemented**: no recordings exist; the bundled-asset path needs none |

## Integration
- Every game (old and new) has a speaker button that reads its instruction in Adam's voice (child-initiated, high priority).
- Automatic narration (off by default, parent switch): game instructions, the "well done / new star" line at the end of a game, and the companion's greeting when the child's home opens.
- New games send sound cues (roll, ladder, slide, place, found, win, gentle...) through the engine. **No effect files exist, so nothing plays for them**, and the engine reports false.
- Leaving a game silences the characters.
- Not integrated yet: Creative Studio, the rewards screens, story narration lines (stories still use their own text-to-speech path), interface sounds (tap, navigate, unlock, notify), background music for the six areas. The catalogue and file paths for them are ready.

## Safety and privacy
No microphone use, no recording of children, no network calls, no AI conversation: only the fixed catalogue lines or an on-screen instruction the app itself already shows.
