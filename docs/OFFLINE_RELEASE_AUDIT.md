**Camera impact analysis:** the gallery picker uses `ImageSource.gallery` only; no `ImageSource.camera`, no camera plugin other than `flutter_webrtc`, which does not declare CAMERA itself (its manifest is empty), so removing the permission and iOS `NSCameraUsageDescription` would not break any offline feature. Removal needs: manifest edit, Info.plist edit, and updating `test/permissions_screen_test.dart`, `test/release_config_test.dart` and the permissions screen (camera row), and it would have to be re-added when video calls are enabled. **APPLIED after the owner's follow-up decision:** CAMERA (and its two uses-feature lines), CHANGE_NETWORK_STATE and iOS NSCameraUsageDescription are removed; the permissions screen, tests and docs were updated. Original recommendation: remove for Release 1 (store forms must match actual use, and a Kids-category review dislikes unused camera access). `CHANGE_NETWORK_STATE` is also unused offline.
